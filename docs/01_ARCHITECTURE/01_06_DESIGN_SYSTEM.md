# Дизайн-система GETVOXLY (Twenty CRM / Table Reference)

> Официальная спецификация интерфейса, дизайн-токенов, сетки и компонентов GETVOXLY.
> Основана на эталонной дизайн-системе Twenty CRM (`https://prarp.twenty.com/objects/opportunities`).

---

## 1. Концепция и визуальная атмосфера

Интерфейс GETVOXLY строится по принципам **Twenty CRM / Table**:
- **Светлый холст (Light Canvas):** основной фон `#ffffff`, боковое меню `#fbfbfb`, границы карточек и секций `#e5e5e5`.
- **Компактная плотность (High Information Density):** табличные строки высотой 32px, компактная шкала типографики (10–13.3px), шрифт Inter для текста и DM Mono для числовых и табличных данных.
- **Дружелюбные скругления:** 16px для карточек и панелей, 8px для кнопок, 4px для инпутов и мелких элементов.
- **Сдержанная палитра:** доминирование монохромных поверхностей (белый, оттенки серого `#666666`, `#888888`) с акцентными функциональными цветами (`#4a38f5` для основного действия, `#03b2cb` для фокуса, `#3b82f6` для Drag & Drop).
- **Паттерн боковых шторок (Slide-Over Drawers):** отсутствие громоздких модальных окон в центре экрана; просмотр и редактирование сущностей происходят в правой панели, привязанной к URL (`?record=<id>`).

- **Основной шрифт (Sans):** `Inter`, sans-serif (веса 400, 500, 600, 700).
- **Моноширинный шрифт (Mono):** `DM Mono`, monospace (числа, суммы, номера нарядов, таймстампы).

### 2.3. Сетка и радиусы скругления (Spacing & Radius)

- **Базовый шаг сетки:** `4px` (все отступы кратны 4px: 4, 8, 12, 16, 20, 24px).
- **Шкала радиусов:**
  - `radius-card` (`16px`): карточки, боковые шторки (на десктопе), пилл-фильтры.
  - `radius-btn` (`8px`): стандартные кнопки и триггеры меню.
  - `radius-subtle` (`4px`): инпуты, селекты, ячейки при редактировании, чипы сущностей.
  - `radius-full` (`9999px`): аватары пользователей, круглые индикаторы статуса.

### 2.4. Тени и глубина (Elevation)

| Уровень | Значение тени | Назначение |
|---|---|---|
| **Subtle** | `rgba(0, 0, 0, 0.004) -4px 4px 4px 0px, rgba(0, 0, 0, 0.039) 0px 2px 4px 0px` | Карточки в канбане, плавающие тулбары |

## 3. Ключевые компоненты

### 3.1. Таблица записей (`RecordTable`)

Геометрия полностью повторяет `RecordTable` Twenty CRM:
1. **Высота строки:** ровно `32px` (`RECORD_TABLE_ROW_HEIGHT = 32`).
2. **Колонка чекбокса:** фиксированная ширина `28px` (`RECORD_TABLE_CHECKBOX_WIDTH = 28`). На мобильном скрывается.
3. **Минимальная ширина колонки:** `104px` (`RECORD_TABLE_COLUMN_MIN_WIDTH = 104`).
4. **Залипание (Sticky columns):** колонка чекбокса и первая колонка (идентификатор записи) залипают при горизонтальной прокрутке (`sticky z-20 bg-white`).
5. **Интерактивные состояния ячейки (3 уровня):**
   - *Display:* статичное значение со значком редактирования (`Pencil`) при наведении.
   - *Focus:* тонкая рамка фокуса для навигации стрелками клавиатуры без активации инпута.
   - *Edit:* инпут ввода с подтверждением по `Enter` или сохранением по `blur`.
6. **Ресайз и перетаскивание:** ширина сохраняется в CSS-переменных `--rt-col-<id>` напрямую через DOM для 60fps без лишних рендеров React.

### 3.2. Боковая панель сущности (`RecordDetailShell` / `DealDrawer`)

Вместо модальных окон в центре экрана используется правая панель:
- Ширина на десктопе: `max-w-[500px]`, рамка слева `border-l border-[#e5e5e5]`.
- Ширина на мобильном (< 768px): на весь экран (`w-full`), без боковой рамки, с кнопкой закрытия 44×44px.
- Заголовок: монограмма сущности (`EntityChip`), название с inline-редактированием, кнопки раскрытия на весь экран и закрытия.
- Вкладки: иконка + компактная подпись с активным индикатором (`Home`, `Timeline`, `Tasks`, `Notes`, `Files`).
- Синхронизация с адресной строкой: открывается как `?record=<id>`, кнопка «Назад» закрывает шторку без ухода со страницы.
