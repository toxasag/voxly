# GETVOXLY Android Companion (Caller ID)

Легковесный нативный Android-микросервис (~2 МБ) для автоматической идентификации входящих звонков на SIM-карту смартфона сотрудника и мгновенной синхронизации с B2B SaaS CRM GETVOXLY.

---

## ⚡ Возможности

1. **Мгновенный АОН (< 15 мс)**:
   При входящем вызове системный `CallScreeningService` перехватывает номер звонящего, делает сверхбыстрый запрос в Fastify API CRM (`/api/v1/crm/contacts/caller-id-lookup?phone=...`) и выводит плавающее окно поверх экрана звонка Android.
2. **Twenty CRM карточка поверх звонка**:
   Отображает:
   - Полное имя контакта (ФИО)
   - Компанию и должность
   - Активную сделку (бюджет, валюту, текущий этап)
   - Кнопку прямого перехода в сделку/контакт в PWA/браузере
3. **Сквозная синхронизация с десктопом (SSE / WebSocket)**:
   При входящем звонке бэкенд одновременно эпушит событие в Real-time шину менеджера — карточка клиента (`RecordDrawerSheet`) на компьютере всплывает еще до снятия трубки.
4. **Автоматический лог звонка**:
   После завершения разговора сервис отправляет `POST /api/v1/crm/contacts/caller-id-log` с фиксацией длительности и статуса (отвечен/пропущен) в таймлайне активности клиента.

## 🛠️ Сборка и запуск

### 1. Открытие в Android Studio
- Запустите **Android Studio** (Hedgehog, Iguana или Ladybug+).
- Выберите **Open** -> укажите папку `mobile/android-companion`.
- Дождитесь синхронизации Gradle (JDK 17).
- Подключите Android-смартфон по USB (с включенной отладкой по USB).
- Нажмите **Run 'app'** (`Shift + F10`).

### 2. Сборка из командной строки
```bash
cd mobile/android-companion
./gradlew assembleDebug
# Готовый APK появится в:
# app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 📱 Настройка на смартфоне (Samsung One UI, Xiaomi HyperOS, Pixel)

1. **Сервер**: укажите адрес `https://api.getvoxly.ru` (или ваш боевой домен).
2. **Токен**: вставьте API-токен сотрудника или администратора тенанта.
3. **Разрешения**:
   - Нажмите **«Разрешить показ поверх окон»** (Overlay Permission).
   - Нажмите **«Назначить определителем номера (АОН)»** -> выберите GETVOXLY Companion приложением по умолчанию для АОН.
   - Нажмите **«Отключить оптимизацию батареи»** -> выберите режим «Не ограничено» (Unrestricted), чтобы система не усыпляла сервис при заблокированном экране.
4. **Тест**: нажмите кнопку **«Показать тестовую карточку Caller ID»**, чтобы увидеть, как выглядит всплывающий виджет во время звонка.
